# 查询实验结果汇总

- 语料：37401 条评论，分词器 custom，avgdl=101.1628
- 查询数：2（作业要求 ≥5；IIR §8.1 的经验下限是 50 条信息需求）
- 深池：每侧取前 50 条；overlap@k 的 k = 5, 10, 20, 50
- 排序 tiebreak：分数降序，同分按 doc_id 升序
- 指标：overlap@k（集合重合，分母固定为 k）+ Kendall τ-b（顺序一致，并集与交集各报一次）
